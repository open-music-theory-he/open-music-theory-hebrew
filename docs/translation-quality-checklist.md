## בדיקות שחוזרים עליהן

הסקריפט `docs/check_translation.py` בודק 47 פרקים: YAML, קיום יעדים מקומיים, שימור כתובות וקבצי המקור, טקסט חלופי לתמונות וטבלת המרווחים בשלמותה. תוצאות גישה מצטברות נשמרות בדוח JSON, כולל מועד בדיקת כל כתובת; זמינות אינה בדיקת ניגון. הסקריפט בודק גם שימור ביטויי תווים, ספירת רכיבי מדיה ו־174 יחידות מבניות במקבץ השני מול המקור הקבוע. הצלחת HTTP אינה אישור שהתוכן נכון או שהמדיה מתנגנת. פרטי הבדיקה ב־`translation-check-results.json`.

להרצה: `python -m pip install markdown beautifulsoup4 pyyaml requests` ואז `python docs/check_translation.py` מתוך המאגר. נדרשת היסטוריית Git הכוללת את נקודת המקור.
