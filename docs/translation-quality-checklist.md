## תוצאות לכל פרק

בכל 17 פרקי המקור בוצעה השוואה לשונית ותוכנית מול המקור. בשני פרקי התוספת בוצעה בדיקת ההסברים והדוגמאות; מבחן התאמה לפרק מקור אינו חל. תוצאות Q08 הן בדיקות מבנה וניתוח Markdown בלבד; בניית Jekyll ממתינה. ב־Q09 קישורים פנימיים עברו, אך בדיקת חוץ וניתוב באתר אינן מלאות. Q10 חלקי בפרקים עם תמונות: alt תורגם אך כיתובי התמונה המקורית לא תורגמו; בפרק המשקל ניגון הסרטונים וההקלטות טרם אומת. Q11 ממתין לתצוגה בפועל אף שנוספה תשתית RTL.

## בדיקות שחוזרים עליהן

הסקריפט `docs/check_translation.py` בודק 19 פרקים: YAML, קיום יעדים מקומיים, שימור כתובות וקבצי המקור, טקסט חלופי לתמונות וטבלת המרווחים בשלמותה. תוצאות גישה מצטברות נשמרות בדוח JSON, כולל מועד בדיקת כל כתובת; זמינות אינה בדיקת ניגון. הסקריפט בודק גם שימור ביטויי תווים, ספירת רכיבי מדיה ו־174 יחידות מבניות במקבץ השני מול המקור הקבוע. הצלחת HTTP אינה אישור שהתוכן נכון או שהמדיה מתנגנת. פרטי הבדיקה ב־`translation-check-results.json`.

להרצה: `python -m pip install markdown beautifulsoup4 pyyaml requests` ואז `python docs/check_translation.py` מתוך המאגר. נדרשת היסטוריית Git הכוללת את נקודת המקור.
