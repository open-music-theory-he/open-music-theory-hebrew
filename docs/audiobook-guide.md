# ספר שמע בעברית — יצוא מדורג

ב־Actions בחרו **Export Hebrew audiobook in stages** ואז **Run workflow**. מצב `generate` יוצר את החלקים הבאים; מצב `prepare` מפיק תמלילים ותוכנית ללא פנייה ל־Gemini. הרצה יומית ב־09:17 UTC ממשיכה אוטומטית. אחרי השלמת כל הפרקים, הרצות נוספות מדלגות עליהם ללא בקשות TTS. כאשר מתווסף פרק מתורגם, הוא מצטרף להרצה הבאה.

המודל היחיד הוא `gemini-3.8-flash-tts`, הקול `Charon`. הנחיית הקריינות הקבועה נמצאת בקובץ `scripts/audiobook-config.json` בשדה `style`; היא נשלחת בתור `speech_metadata`, בנפרד מהטקסט המוקרא. אין החלפה אוטומטית של מודל ואין שימוש במודל טקסט אחר כדי לכתוב מחדש את הפרקים. גוגל מציגה את Flash TTS כמכוון לספרי שמע וקריינות ארוכה, עם מסלול חינמי ב־Standard. שני דגמי 3.8 משתמשים באותה סכמת API; הקוד משתמש רק ב־Flash.

המפתח נשמר ב־Repository secrets תחת השם `GEMINI_API_KEY`. הפרויקט שנבחר ב־AI Studio סומן Free tier בעת ההגדרה ב־7 באוקטובר 2026. **יש להשאיר אותו במסלול ללא חיוב**: ל־Gemini API אין דגל בבקשה המבטיח שימוש חינמי, ואם מפעילים חיוב בפרויקט הוא עלול לחייב עבור אותה בקשה. המכסה בפועל נקבעת לפי הפרויקט ועשויה להשתנות. אין הפעלה של חיוב או מעבר למסלול בתשלום בתהליך היצוא.

כל פרק מתורגם מופק כקובץ MP3 אחד, בשם עברי ובסדר הספר. פרק ארוך מחולק פנימית לקטעים קצרים, ואז מחובר בלי קידוד חוזר. לאחר כל קטע מוצלח נשמרים השמע, גיבוב הטקסט וגיבוב הקובץ בענף `audiobook-data`. ב־429 ההרצה נעצרת מיד, מציגה `paused` ושומרת התקדמות; היא אינה מסתובבת בניסיונות חוזרים ולא מחליפה מודל. תקלת שירות או רשת גם עוצרת ושומרת. שגיאת הרשאה, מודל לא זמין או שמע לא תקין מסומנת `error`. הרצה נוספת משתמשת בקטעים השמורים וממשיכה מהראשון החסר. יש גם מגבלת זמן ומספר בקשות לכל הרצה.

הענף הנפרד שומר את ההתקדמות מעבר לתוקף ה־artifacts. השינוי בפרק או בהגדרות המודל, הקול, הסגנון או חלוקת הקטעים יוצר מזהה חדש, כך שאין חיבור בין גרסאות שונות. פרקי גרסה קודמת נשמרים בענף, אך אינם נכללים בספר השמע של הגרסה הנוכחית. הרשאת `contents: write` של ה־workflow נדרשת לשמירת קטעי השמע בענף זה. `concurrency` מונע משתי הרצות לשנות אותו במקביל.

באזור Artifacts מופיע `hebrew-audiobook`. הוא כולל תיקיית `chapters` עם קובץ לכל פרק שהושלם, תיקיית `transcripts` עם התמלילים המוקראים, תוכנית ודוח התקדמות, ו־ZIP עברי של התוצרים. פרק שלא הושלם אינו מוצג כקובץ שמע סופי.

זו קריינות של המלל, ולא ביצוע מוזיקלי של דוגמאות התווים. איורים מיוצגים באמצעות תיאור ה־alt שקיים במקור והפניה לגרסה הכתובה; אין ניחוש של הצלילים שבתמונה. טבלאות נקראות שורה אחר שורה ומתועדות כמצריכות בדיקת האזנה. שמות תווים ABC נכתבים בתמליל כשמות האותיות בעברית, עם דיאז/במול/מספר אוקטבה. סימונים רומיים, נוסחאות וסימונים מורכבים מסומנים לבדיקה. הקריינות אינה הופכת את הספר לספר לימוד שניתן ללמוד ממנו בלי התווים והאיורים.

בדיקות אוטומטיות מכסות את סכמת בקשת 3.8, שמירת כל תווי הטקסט בחלוקה, עצירה במכסה וחידוש ללא יצירה כפולה, גיבובי קבצים ופענוח MP3. מצב `generated_needs_listening_review` אומר שהקובץ נוצר ונבדק טכנית; הוא **אינו אישור** שכל המילים והסימונים הוקראו נכון. יש להאזין במיוחד לשמות תווים, דרגות והרמוניות, לשפות מעורבות ולגבולות בין קטעים.

הקוד משתמש ב־Interactions API בתשובת WAV מלאה, ולא במעטפת PCM של דגמי TTS הישנים. אין מפתח בכתובת URL, בקוד או בדוח, וגופי שגיאות מרוחקים אינם מודפסים.

מקורות גוגל שנבדקו ב־7 באוקטובר 2026:

- [מדריך TTS וסכמת REST](https://ai.google.dev/gemini-api/docs/speech-generation)
- [השוואת Flash ו־Flash-Lite](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-lite-tts)
- [מחירים ומסלול חינמי](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.8-flash-tts)

להרצה מקומית ללא API:

```bash
python -m pip install -r scripts/requirements-audiobook.txt
python -m unittest discover -s scripts -p 'test_audiobook.py' -v
python scripts/export_audiobook.py --prepare-only
```

הקרדיטים ורישיון המהדורה הכתובה חלים גם על המלל המוקרא. בכל פרק מצוין שהקריינות נוצרה בבינה מלאכותית. אין הקלטה או שכפול של קול אדם; נעשה שימוש בקול מובנה של גוגל.

## תנאי כניסה להפקת שמע

רק פרקים שתרגומם נבדק מול המקור, במצב `language-reviewed` או `completed`, נכללים בהפקה. פרק ללא מצב תרגום, פרק חלקי (`partial`), טיוטה (`translated`) או פרק הממתין להכרעת עריכה אינם נשלחים למודל השמע. עצם קיומו של שדה מצב אינו מספיק. עמודי ניווט ותוכן עניינים אינם פרקי שמע. פרקי מקור נוספים יצטרפו אוטומטית רק לאחר השלמת בדיקת התרגום וסימון המצב המתאים. בדיקת לשון אינה מחליפה את בדיקת ההאזנה ואת בדיקות המדיה והתצוגה.
