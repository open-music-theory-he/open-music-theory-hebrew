## דף עבודה: מרווחים לפי מספרם הדיאטוני {#v2-generic-intervals-worksheet}

**מקור:** Chelsey Hamm, דף העבודה <bdi dir="ltr">Generic Intervals</bdi>, מתוך [המקלדת ומערכת שתי החמשות, גרסה 2](https://viva.pressbooks.pub/openmusictheory/chapter/the-keyboard-and-grand-staff/).

[דף העבודה המקורי, שלושה עמודים](Worksheets/omt-v2/004-3.pdf). ההוראות והשאלות המילוליות מתורגמות כאן; התרגילים שעל החמשות נשמרו בקובץ המקורי. בתרגיל זה נדרש מספר המרווח בלבד, בלי לקבוע את איכותו. יש לספור גם את תו ההתחלה כ־1.

### חלק 1: מרווח מעל תו נתון

כתבו את שם האות הנמצאת במרווח המבוקש מעל התו הנתון. אל תשכחו לספור את התו הראשון כ־1. דוגמה: טרצה מעל <bdi dir="ltr">D</bdi> היא <bdi dir="ltr">F</bdi>.

### חלק 2: מרווח מתחת לתו נתון

כתבו את שם האות הנמצאת במרווח המבוקש מתחת לתו הנתון. גם כאן סופרים את התו הראשון כ־1. דוגמה: טרצה מתחת ל־<bdi dir="ltr">D</bdi> היא <bdi dir="ltr">B</bdi>.

הטבלה מרכזת את כל שאלות שני החלקים. שתי העמודות הימניות אחרי אות הסעיף הן לחלק 1, עלייה; שתי העמודות הבאות הן לחלק 2, ירידה. קו מפריד מציין שאין שאלה באותו סעיף בחלק 1.

### חלק 3: כתיבת מרווח מעל תו או מתחתיו

כתבו במערכת שתי החמשות את התו הנמצא במרווח המבוקש מעל התו הנתון או מתחתיו. זכרו לספור את התו הראשון כ־1. חץ כלפי מעלה, ↑, מציין עלייה; חץ כלפי מטה, ↓, מציין ירידה. בדף המקור שתי סדרות, A ו־B, ובכל אחת עשר שאלות המסומנות a–j. ההוראה בכל שאלה היא:

| שאלה | המרווח המבוקש |
|---|---|
| a | טרצה מעל |
| b | קווינטה מעל |
| c | סקונדה מתחת |
| d | קוורטה מתחת |
| e | אוקטבה מעל |
| f | טרצה מתחת |
| g | סקונדה מעל |
| h | סקסטה מתחת |
| i | ספטימה מתחת |
| j | קווינטה מעל |
